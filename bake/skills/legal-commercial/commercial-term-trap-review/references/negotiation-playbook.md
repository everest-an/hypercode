# Negotiation Playbook

## 1. Classify the gap

Quantify the difference in **effective all-in cost**, not headline rate.

| Gap | Default play |
|---|---|
| < 0.3% of turnover | Speed usually wins. Ask once; if refused, trade for a non-cash term. |
| 0.3–1.0% of turnover | Ask for written clarification; use prior version/bill; trade for free rent or fee cap. |
| > 1.0% of turnover | Escalate. Do not sign until the economics are approved or an alternative is priced. |

The gap should be measured at base sales, not at an optimistic case.

## 2. Build the comparison

Show three columns:

| Item | Prior version | New version | Delta |
|---|---|---|---|
| Headline rent | | | |
| Tax treatment | | | |
| Effective rent | | | |
| Property / service fee | | | |
| Deposit | | | |
| Free rent | | | |
| All-in cost | | | |

A one-page table is more persuasive than a long argument.

## 3. Use the strongest evidence, in order

1. **Signed contract** for the same or comparable unit.
2. **Actual bills** showing how the line item was settled.
3. **Prior term sheet** with the same or comparable terms.
4. **Market comparables** from other landlords.
5. **Alternative location** with a written offer.

Do not lead with "we remember it was inclusive". Lead with the document.

## 4. Trade list

If the counterparty will not move on the tax scope, trade for value elsewhere:

- additional rent-free / fit-out days;
- cap on service/property fee increases;
- deposit reduction (months or basis);
- marketing/promotion fund contribution;
- fit-out contribution or allowance;
- rent commencement tied to opening, not delivery;
- early termination compensation for unamortized fit-out;
- signage / façade / visibility;
- exclusivity or co-tenancy remedy;
- flexible delivery long-stop;
- payment terms / invoice timing.

Rank each trade by **cost to landlord** and **value to tenant**. Ask for the cheapest thing for them that is valuable to you.

## 5. Leverage

- **Speed:** a signed deal this month is valuable to a leasing team.
- **Anchor traffic:** a concept that drives footfall is valuable beyond rent.
- **Portfolio:** more than one unit or city gives you a portfolio conversation.
- **Alternative:** a real competing offer changes the conversation; a bluff does not.
- **Publicity / events:** launches, pop-ups and content can be part of the package.
- **Data / AI:** a retail operating system can be valuable to the landlord's other assets.

## 6. Red lines

Do not sign without:

- a written tax matrix for every line item;
- a defined turnover formula;
- a deposit basis and refund period;
- a cap or remedy for unilateral fee increases;
- a handover condition report;
- a restoration cost cap or fixed restoration fee;
- a long-stop delivery date with a termination right;
- a break-right compensation formula if the landlord can terminate early.

## 7. Sequence

1. Confirm the commercial deal points (term, rent, fees, deposit).
2. Confirm the tax matrix.
3. Confirm the open items in one email.
4. Ask for the draft contract with the agreed language.
5. Redline the contract against the term sheet.
6. Sign only when the contract matches the matrix.

Do not let the counterparty move to contract before the tax matrix is closed. Once the draft is issued, changes become "legal comments" and take longer.

## 8. Decision log

For each deal, record:

```text
Deal:
Counterparty:
Version:
Headline:
Effective cost (low/base/high):
Open items:
Decision:
Owner:
Next date:
```

Review the log weekly. Patterns repeat across landlords and cities.
