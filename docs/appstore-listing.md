## 四、审核注意事项（Mac App Store）

1. **沙盒化**：Mac App Store 应用需开启 App Sandbox。HyperCode 桌面版需要文件系统访问（读写项目文件），需声明 `com.apple.security.files.user-selected.read-write` 等 entitlement。
2. **网络**：需声明 `com.apple.security.network.client`（调 DeepSeek API）。
3. **隐私**：App 会访问用户的项目文件和 API key，隐私政策里已覆盖（`/privacy` 页）。
4. **版本号**：Mac App Store 要求 CFBundleShortVersionString 与版本号一致（当前 0.1.18）。

> 注：如果 HyperCode 桌面版当前不是按 Mac App Store 沙盒规范构建的，可能需要在 electron-builder 配置里加 `mas` target + entitlement 文件。这是工程改动，需另行处理。
